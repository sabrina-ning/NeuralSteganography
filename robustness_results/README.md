# Robustness Results

This directory stores outputs from multi-seed robustness evaluations of the pixel optimization algorithm.

Files in this directory are not tracked by git. They are generated by:
- `scripts/run_robustness_eval.py` — Runs Setup 1 optimization across multiple seeds and images

Each run produces:
- `recovered_{image}_{seed}.png` — The optimized cover image
- `loss_{image}_{seed}.png` — The optimization loss curve
- `diff_{image}_{seed}.png` — Pixel difference visualization
