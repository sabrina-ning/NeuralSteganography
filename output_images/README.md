# Output Images

This directory stores images generated by the steganography pipeline scripts.

Files in this directory are not tracked by git. They are generated by:
- `scripts/run_pixel_optimization.py` — Setup 1/2 optimization results
- `scripts/run_image_steganography.py` — End-to-end pipeline cover images and recovered secrets
- `scripts/run_image_generation.py` — Emu3 image generation/reconstruction tests
